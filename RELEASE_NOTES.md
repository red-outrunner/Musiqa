# Musica 1.0.0

The first public release of Musica, an offline music player by **weo sikho fuzile**.

- Browse albums, artists, genres, and folders; scan your library when you choose.
- Use four named queues, playlists, favorites, Most Played, and smart playlists.
- Open Now Playing, search the queue, reorder songs, and undo queue/playlist edits.
- Edit tags and embedded covers offline, including batches of songs.
- Adjust crossfade, gapless playback, ReplayGain, mono/stereo, and the equalizer.
- Choose light/dark themes, text sizes, columns, and artwork or list views.
- Use local lyrics, bookmarks, backup/restore, sharing, and Linux desktop controls.

Download the **Windows ZIP** below, extract the entire package, and open `bin/musicplayer.exe`. Windows may need the [Microsoft Visual C++ x64 runtime](https://aka.ms/vs/17/release/vc_redist.x64.exe).

Windows targets Windows 10/11 x64. Linux portable and ARM packages are not included. The Windows package passes the packaged-app startup check; live playback and some other CI checks still fail, so this build has known validation limitations.

The source archive matches this release. `SHA256SUMS.txt` lists the download checksums. See the [README](https://github.com/red-outrunner/Musiqa/blob/v1.0.0/README.md) for the short usage guide.
